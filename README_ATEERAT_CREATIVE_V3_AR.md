# عطيرات — المحرك الإبداعي البصري V3

هذا تحديث حقيقي للمشروع الموجود في GitHub (`ateerat1`)، وليس إنشاء متجر جديد. يحافظ على الكتالوج الحالي من **www.ateerat.com** والمسودات وهوية عطيرات (شعار كحلي/أبيض + خط Cairo)، ويضيف توليد خلفيات سينمائية بواسطة نموذج صور خارجي **عند تفعيله صراحة**.

## ماذا يفعل؟

1. يحصل على المنتج المسموح بتسويقه من كتالوج Odoo الحالي، ويتأكد من الاسم والسعر والتوفر والصورة قبل التصميم.
2. يحدد لوحة ألوان من صورة المنتج الأصلية.
3. ينتقي أحد **ثمانية اتجاهات فنية**، وينوعها حسب المنتج والشهر، مثل الفن المعماري المضيء، الكريستال، الزجاج السائل، المشاهد الليلية والإضاءات النحتية.
4. يطلب من واجهة الصور إنشاء **الخلفية فقط**، بلا عطر أو نص أو شعار أو أسعار.
5. يركّب `marketing_cards.py` **الصورة الأصلية للزجاجة من عطيرات**، ثم الشعار والخط والسعر الصحيح والشريط السفلي برمجيًا.
6. يحفظ الصور والمسودات للمراجعة؛ **لا ينشر أي شيء**، ولا يغيّر إعدادات Metricool أو Meta.

عندما لا تتوفر واجهة توليد الصور، يعود تلقائيًا إلى خلفية V2، ولا يُعطّل إعداد الإعلانات.

## ملفات التحديث المطلوب رفعها

ارفع هذه الملفات فقط؛ **لا تحذف الملفات الأخرى**.

| ملف التحديث | المكان داخل مستودع GitHub |
| --- | --- |
| `creative_backgrounds.py` | الصفحة الرئيسية بجوار `catalog.py` |
| `marketing_cards.py` | استبدال الملف الموجود في الصفحة الرئيسية |
| `test_creative_backgrounds.py` | داخل مجلد `tests` |
| `test_marketing_cards.py` | استبدال الملف الموجود داخل `tests` |
| `catalog-sync.yml` | استبدال محتوى `.github/workflows/catalog-sync.yml` عبر رمز القلم Edit |

> النسخة المسطحة `catalog-sync.yml` داخل الملف المضغوط هي نفس الملف الموجود داخل المسار `.github/workflows`، لتسهيل النسخ واللصق من متصفح GitHub.

**لا ترفع مجلد `assets` ولا تحتاج إلى إعادة رفع شعاراتك وخط Cairo.** استخدم الملفات الموجودة بالفعل داخل مستودع عطيرات. حزمة التحديث لا تحتوي على الخط.

## الاختبار المجاني أولًا

من `Actions` شغّل `Ateerat public catalog sync` على الفرع `main` بعد الرفع.

- يجب أن تنجح الاختبارات وإنشاء الكتالوج والبطاقات.
- عند عدم تفعيل الذكاء الاصطناعي تُولّد تصاميم V2 كالمعتاد. هذا متوقع.
- تأكد أن `marketing/cards_manifest.json` يعرض `design_version: ATEERAT-V3` وأن `background_mode` يكون `V2-ABSTRACT-FALLBACK` قبل تشغيل الـ API.

## تفعيل توليد الخلفيات بالذكاء الاصطناعي (مدفوع واختياري)

خدمة توليد الصور عبر OpenAI API **ليست مشمولة تلقائيًا باشتراك ChatGPT**، وقد تتطلب إعداد الفوترة والتحقق من مؤسسة API حسب الحساب. احرص على وضع حد للإنفاق داخل حساب API إن كان متاحًا ومتابعة لوحة الاستخدام. التكلفة حسب النموذج والجودة والاستخدام الفعلي.

1. أنشئ مفتاح API من لوحة المطورين الرسمية. **لا ترسل المفتاح في محادثة أو تضعه داخل GitHub Code**.
2. GitHub → مستودع `ateerat1` → `Settings` → `Secrets and variables` → `Actions` → تبويب `Secrets` → `New repository secret`.
3. الاسم حرفيًا: `OPENAI_API_KEY`، والقيمة: المفتاح السري.
4. في تبويب **Variables** اختر `New repository variable`: الاسم `ATEERAT_CREATIVE_AI_ENABLED`، والقيمة `true`.
5. من `Actions` اختر مهمة `Ateerat public catalog sync` ثم `Run workflow` على `main`.

بالتفعيل يطلب النظام **صورة خلفية جديدة واحدة بحد أقصى لكل تشغيل** (قد تكون أقل إذا وجد صورة مخزنة للمنتج/الفكرة). يحفظ النسخة لإعادة استخدامها بدل دفع التكلفة مجددًا. إذا شغّلت المهمة عدة مرات يدويًا وكانت هناك أفكار جديدة غير مخزنة فقد تترتب رسوم إضافية في كل تشغيل.

لإيقاف توليد الصور المدفوع، غيّر قيمة المتغير إلى `false` أو احذفه. لا يحتاج ذلك إلى حذف المفتاح.

## أين تظهر النتائج؟

- `marketing/creative_backgrounds/*.jpg` — الخلفيات السينمائية فقط.
- `marketing/creative_backgrounds_manifest.json` — ربط الخلفيات بالمنتجات الحقيقية.
- `marketing/cards/*.png` — إعلان عطيرات النهائي 1080 × 1350.
- `marketing/cards_manifest.json` — قيمة `background_mode` تصبح `AI-CINEMATIC` للإعلانات ذات الخلفية الجديدة؛ وتبقى `V2-ABSTRACT-FALLBACK` للبقية.
- `marketing/preview.html` — معاينة الصور والنصوص (قد تحتاج فتح الملف محليًا لمعاينة HTML).

**ملاحظة:** أول تشغيل مدفوع يصنع خلفية إبداعية واحدة فقط، وليس سبع خلفيات؛ وذلك لتجنب رسوم مفاجئة. بقية المنشورات تظل في الوضع السابق حتى يحصل كل منها على خلفية مخزّنة.

## السلامة ودقة الهوية

- لا تُستبدل زجاجة العطر بنسخة مولدة أو مقلّدة.
- لا تُولّد أرقام أسعار أو خصومات أو نسب تشابه أو ادعاءات بمكونات الروائح.
- يبقى `auto_publish: false`، والتصاميم للمراجعة فقط.
- خلفيات الذكاء الاصطناعي قد تتضمن عيوبًا بصرية؛ افحص الناتج قبل استخدامه تجاريًا.
- نموذج الصور الخارجي يستلم وصفًا فنيًا للألوان والأسلوب، وليس بيانات عملاء Odoo أو أسرار GitHub. لا ترسل له ملف الكتالوج كاملاً.
- إذا لم تظهر الخلفيات السينمائية، افحص اسم متغير `ATEERAT_CREATIVE_AI_ENABLED` ثم خطوة `Create one cinematic AI background...` من `Actions`.

## ملاحظات فنية

- واجهة التوليد: `POST https://api.openai.com/v1/images/generations`، النموذج الافتراضي `gpt-image-2.5-flare`، الجودة `medium` والصورة `1024x1536` تتحول إلى `1080x1350`.
- كل صورة مولّدة تحفظ في Cache باسم مشتق من هوية المنتج ونوع الفكرة والشهر.
- حد الإنفاق البرمجي لكل تشغيل هو صورة جديدة واحدة في GitHub؛ والحد الأعلى المقبول داخل CLI هو ثلاث صور، لكنه ليس حدًا ماليًا شهريًا.
- لا يُطلب `openai` SDK إضافي؛ الكود يستخدم `requests` و`Pillow` المثبتتين في المشروع.
