# موصل كتالوج عطيرات — نموذج أولي

**المصدر المعتمد الوحيد:** https://www.ateerat.com/

هذه أداة لقراءة المنتجات **المنشورة للعامة** من متجر Odoo Online Standard دون كلمة مرور ودون External API. ليست أداة للنشر التلقائي، ولا تجلب المخزون الداخلي. تُخرج ملف JSON وCSV وملف التغيرات، ليمثلوا المرحلة الأولى من وكيل التسويق.

## لماذا هذا المسار؟

اشتراك Odoo Online Standard لا يدعم واجهة External API الرسمية. لكن مواقع Odoo تستخدم عادة خريطة `/sitemap.xml` وبيانات المنتج المنظمة، ويمكن اختبار الاستفادة منهما دون تعديل موقعك.

**تنبيه:** لم نتمكن في جلسة ChatGPT من الوصول المباشر إلى صفحة عطيرات، لذلك يعمل الكود كنموذج أولي يحتاج التجربة الفعلية على شبكتك أو على GitHub Actions. **لم يتم التحقق من سعر المنتج هيرش 2 أو صورته.**

## طريقة التشغيل

1. ضع ملفات المشروع في مستودع GitHub جديد.
2. من جهازك، أو بيئة تدعم Python 3.11+، ثبّت المتطلبات:

```bash
pip install -r requirements.txt
```

3. لاختبار المنتج الذي أرسلته فقط:

```bash
python catalog.py
```

4. لاكتشاف بقية المنتجات من خريطة الموقع:

```bash
python catalog.py --all --max-products 200
```

5. نتائج التشغيل في:

- `data/catalog.json` — البيانات المنظمة للمنتجات.
- `data/catalog.csv` — جدول المنتجات.
- `data/changes.json` — المنتجات الجديدة والتغييرات (مقارنة بالتشغيل السابق).

إذا تعذر الوصول إلى الموقع أو لم يظهر أي منتج، يتوقف البرنامج **بدون استبدال الكتالوج السابق بملف فارغ**.

## تجربة آمنة دون الإنترنت

للتأكد من آلية قراءة صفحة Odoo، استخدم صفحة HTML تجريبية **غير حقيقية** ضمن الملفات:

```bash
python -m unittest discover -s tests -v
python catalog.py --html-file tests/fixtures/odoo_product.html --out test_output
```

لا تنشر أي بيانات من ملف `test_output`؛ فهي مثال فقط.

## تشغيل تلقائي على GitHub Actions

بعد رفع جميع الملفات إلى المستودع، افتح GitHub → Actions → `Ateerat public catalog sync` → `Run workflow`.

الملف `.github/workflows/catalog-sync.yml` يحتوي على جدول يومي تقريبي الساعة 09:15 صباحًا بتوقيت اليمن. مواعيد تشغيل GitHub Actions ليست مضمونة بالدقيقة. عند نجاح التشغيل، تحفظ النتائج في المستودع. إذا لم تتمكن GitHub من الوصول إلى الموقع، سيظهر الخطأ في سجل التشغيل، ولن تُخترع أي منتجات.

**ملاحظة الخصوصية:** إذا كان المستودع عامًا، فإن ملفات الكتالوج التي يُنشئها ستكون عامة أيضًا. لا تخزّن فيه بيانات عملاء أو بيانات دخول. وإن كان الموقع يمنع زحف صفحات المنتجات عبر robots.txt فاحترم الحظر وعدّل إعدادات النشر/الفهرسة من لوحة الموقع بدلاً من تجاوزه.

## بوابة السلامة قبل إنشاء أي إعلان

الحقل `ready_for_automated_ad` يصبح صحيحًا فقط عندما تكون الصورة والسعر والعملة **وحالة InStock** مؤكدة في بيانات صفحة المنتج. إذا لم يكشف الموقع توفر المنتج، تكون القيمة `false`، ويجب التحقق من التوفر بطريقة معتمدة قبل السماح بنشر آلي. ولا تُنشأ خصومات من تلقاء النظام.

## الخطوة التالية

بعد نجاح استخراج المنتجات الحقيقية، نحدد نموذج المحتوى العربي وهوية التصاميم، ثم نربط تحويل كل منتج معتمد إلى مواد تسويقية وجدولتها عبر Metricool. هذا **الربط لم يُنفذ بعد**؛ الأداة هنا مرحلة استخراج المنتجات فقط.
