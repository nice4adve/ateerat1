# عطيرات — المرحلة الثالثة: صناعة منشورات مصوّرة تلقائيًا

## الوظيفة

يراجع البرنامج أحدث كتالوج Odoo من `www.ateerat.com` والمسودات الآمنة، ثم يجلب الصورة **الأصلية** من المتجر ويركبها في تصميم عمودي 1080 × 1350 بكسل مع اسم المنتج وسعره الحالي. لا يخلق صور منتجات وهمية ولا ينشر تلقائيًا. ويوقف العمل إذا تغيّر السعر أو الصورة بين الكتالوج والمسودة.

## ملفات هذا التحديث

1. `marketing_cards.py` — يوضع في جذر المستودع بجوار `catalog.py` و`marketing_drafts.py`.
2. `tests/test_marketing_cards.py` — يوضع داخل مجلد `tests`.
3. `requirements.txt` — استبدل الملف الموجود بهذا الملف ليُثبِّت Pillow.
4. `.github/workflows/catalog-sync.yml` — استبدل ملف التشغيل الموجود بهذا الملف لربط المراحل الثلاث.

**لا تحذف** `catalog.py` أو `marketing_drafts.py` أو `data`.

## التشغيل

من GitHub: Actions → Ateerat public catalog sync → Run workflow → فرع main.

بعد نجاح التشغيل، من تبويب Code افتح:

- `marketing/cards` — صور PNG للمنشورات السبعة.
- `marketing/preview.html` — معاينة وتفاصيل الصور والنصوص.
- `marketing/cards_manifest.json` — أسماء ملفات الصور، وروابط منتجاتها ونصوص المنشورات.

لا يوجد نشر على Facebook أو Instagram في هذه المرحلة. عبارات الإعلان مقتصرة على حقائق الكتالوج؛ يجب مراجعة السعر والتوفر قبل السماح بنشر مؤجل. إذا لم تُحمّل صورة أصلية لمنتج واحد، تنتهي المهمة بخطأ واضح بدل إنتاج تصميم زائف.

### بخصوص النشر التلقائي المستقل

Metricool MCP داخل ChatGPT يمكنه إنشاء منشورات مجدولة بموافقتك بحسب الصلاحيات. أما برنامج يعمل من GitHub بدون ChatGPT ويجدول مباشرةً عبر Metricool API، فيحتاج اشتراك Metricool Advanced أو Custom بحسب توثيق Metricool الحالي. لا تدخل أي رموز سرية في ملفات GitHub العامة.

### ملاحظة تصميمية

استخدمنا ألوانًا أولية كحلي/ذهبي، وليست بالضرورة هوية عطيرات النهائية. قبل النشر نُعدّل الخطوط والألوان ونضع الشعار الأصلي الذي تُزوّدنا به. النصوص ما زالت قوالب آمنة وليست ناتجة عن نموذج لغوي؛ دمج توليد النصوص الإبداعية يتم لاحقًا مع آليات حماية الأسعار والمعلومات.
